클로드 코드 강의

19화: API 키 연결 — 어디에 두고 어떻게 확인하는가

나루메모나 원고 띄우기처럼 앱이 직접 클로드를 부르는 프로젝트는 API 키가 따로 필요하다. 구독(클로드 프로)과는 지갑이 다른 자리라, 이쪽은 쓴 만큼 청구된다고 보면 된다. 지켜야 할 규칙은 하나다 — 키는 코드에 적지 않는다. 프로젝트 폴더의 .env 같은 파일에 두고, 그 파일 이름을 .gitignore에 올려 깃이 따라가지 못하게 막는다. 실수로 깃허브에 올라간 키는 지워도 커밋 기록에 남으니, 그때는 지우는 게 아니라 키를 폐기하고 새로 발급하는 게 정답입니다.

실습: 나루메모 폴더에서 "이 프로젝트가 API 키를 어디서 읽어오는지 찾아서 알려줘. 키 값 자체는 보여주지 말고"라고 부탁해보자. 그다음 ".gitignore에 그 파일이 들어 있는지 확인해줘"까지 이어서 물으면, 지금 상태가 안전한지 한 번에 점검됩니다.

합천 원폭 이야기와 『오뒷세이아』 안내서는 후보에 다시 올라왔지만 어제 이미 실어서 뺐습니다. 프시케의 편지 글은 수집 루틴이 봇 검문에 막혀 티저만 봤던 것인데, 오늘 브라우저로 열어 본문을 읽고 실었어요.
