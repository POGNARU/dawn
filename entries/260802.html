클로드 코드 강의

7화: 파일 탐색 — Glob/Grep

클로드 코드는 파일 이름 패턴이나 코드 안의 특정 단어를 순식간에 찾아준다. Glob은 "이런 이름의 파일들"을 패턴으로 찾고, Grep은 파일 내용 안에서 원하는 문구나 함수를 찾아낸다. 프로젝트가 커질수록 손으로 뒤지는 대신 이 둘을 부르는 게 훨씬 빠르다.

실습: "src 폴더에서 .js 파일 다 찾아줘"라고 말해보자. 이어서 "이 프로젝트에서 '로그인'이라는 단어가 들어간 파일 찾아줘"라고 물으면, 클로드가 코드 전체를 뒤져 관련 위치를 짚어준다.
