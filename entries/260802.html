The Marginalian. 융은 만년의 편지에서 "시간 안의 존재와 나란히 흐르는, 시간 밖의 존재"를 상상했다. 의식은 시간과 발맞춰 가지만 무의식은 다른 시간의 층에 있을지 모른다는 것. 「죽음과 영혼」에서 그는 삶의 곡선을 던져진 물체의 포물선에 빗댄다 — 올라갔다가 다시 고요로 되돌아오는 궤적. 중년을 쇠락이 아니라 다시 태어나는 자리로 읽는 글.

"죽음 또한 소멸이 아닌 시간의 계주"

경향신문 '책과 삶'. 은희경이 7년 만에 낸 장편 『시간의 감촉』 — 『새의 선물』, 『빛의 과거』를 잇는 '시간 3부작'의 마지막 권이다. 같은 해에 태어난 자매 안나와 경선, 그리고 경선의 손녀 다니엘. 미혼인 안나가 다니엘을 돌보며 과거와 현재를 되짚는다. "안나는 미혼이라 죽으면 끝이라 여기기 쉽지만, 모든 삶은 연결돼 있고 느슨한 연대 속에 있다"는 작가의 말이 소설의 축이다.

클로드 코드 강의

7화: 파일 탐색 — Glob/Grep

파일이 어디 있는지 몰라도 된다. Glob은 이름 패턴으로 파일을 찾고(예: 모든 .js 파일), Grep은 파일 안의 내용을 찾는다(예: 'login'이라는 단어가 들어간 파일). 폴더를 하나씩 열어보지 않아도 "그거 어디 있더라"가 한 번에 해결된다.

실습: "src 폴더에서 .js 파일 다 찾아줘"라고 부탁해보자. 이어서 "그중에 'login'이라는 말이 들어간 파일만 알려줘"라고 하면 Grep이 내용까지 훑어준다.

닿지 못한 곳: 오늘은 클라우드 실행 환경의 외부 접속 정책에 막혀 RSS 피드(브레비티·파리 리뷰·프시케·디스 융지언 라이프·마지널리안·이온)와 한국어 피드(오늘의 철학·경향·오마이뉴스·굿뉴스) 어느 곳도 직접 열지 못했어요. 웹 검색으로만 글을 찾아 평소보다 편수가 적고, 고전·인문 칸과 신앙 칸은 비웠습니다.
