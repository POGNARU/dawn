클로드 코드 강의

6화: Git 연동 — 상태 확인·커밋

클로드 코드는 터미널 밖으로 나가지 않고도 git 상태를 확인하고 커밋까지 대신 해준다. "무엇이 바뀌었는지 보여줘"라고 물으면 변경 사항을 정리해 보여주고, "이 변경사항 커밋해줘"라고 하면 알맞은 커밋 메시지를 지어 커밋한다.

실습: "git status 보여줘"라고 물어본 뒤, 이어서 "이 변경사항 커밋해줘"라고 부탁해보자. 클로드가 변경 파일을 정리하고 커밋 메시지까지 지어 보여준다.
